EMERGENCY PREPAREDNESS & RESPONSE RESOURCE & ASSET GUIDE
Static web deployment package

NETLIFY DROP
1. Open https://app.netlify.com/drop
2. Drag this entire folder onto the page.
3. Netlify will publish it and provide an HTTPS URL.

GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html to the repository root.
3. Enable GitHub Pages for the main branch/root folder.
4. GitHub will provide an HTTPS Pages URL.

The index.html file is self-contained and does not require an image folder,
server, database, or special software.
